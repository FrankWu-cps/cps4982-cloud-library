How search works

PySpark builds a term–document index from the real Lab2 texts. Django serves the same indexed weights through a read-only search database; no language model invents the results.

Original texts→PySpark TF-IDF→Parquet / SQLite→Ranked results

Ranking formula

TF = term count / document tokens
IDF = ln((N + 1) / (DF + 1)) + 1
score = Σ(TF × IDF) × matched query terms / unique query terms

Scores are relative to this collection, not a quality rating. Exact-phrase mode also checks the original text. This is lexical search, not translation or semantic AI search.
